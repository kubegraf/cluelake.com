# cluelake.com

Marketing site for **ClueLake** — Decision intelligence for the data-rich, time-poor.

Live: https://kubegraf.github.io/cluelake.com/

Editorial sidebar layout · serif headlines + mono ticker · paper-vs-dark chapter alternation · live signal feed · constellation map · comparison-table pricing · ask-the-lake textarea CTA. Each chapter is a deep section, not a card.

React 19 + TypeScript + Vite 6 + Tailwind 4. Deploys to GitHub Pages on push to main.
